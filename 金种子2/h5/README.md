# 韶山红 · 红色研学数字地图（H5 原型）

面向学校、研学机构与散客的移动端红色研学导览原型。以韶山核心景区为首个试点，把「数字地图导览 / 主题线路 / 红色故事 / 互动研学任务 / 机构定制服务」串成一条完整链路，所有内容由 `data.js` 驱动，后续增加其他红色景点只需追加数据，不改页面代码。

- 版本：`v0.1.0 试点版`（`data.js` 的 `meta.version`）
- 形态：纯静态 H5，零依赖、零构建、无 CDN，可离线运行
- 目标屏：手机竖屏 375–430 宽；桌面浏览器自动套 440px 手机框

---

## 一、运行方式

**方式 1（最简单）**：直接双击 `index.html`，用 Chrome / Edge 打开即可。项目不发起任何网络请求，`file://` 下功能完整（含 canvas 生成证书）。

**方式 2（推荐做演示）**：在 `h5` 目录起一个静态服务，手机与电脑同网段时可扫码访问：

```powershell
cd D:\金种子2\h5
python -m http.server 8777 --bind 0.0.0.0
# 电脑访问 http://127.0.0.1:8777/
# 手机访问 http://<电脑局域网IP>:8777/
```

> 用 `python -m http.server` 时若改了 `assets` 下的文件看不到变化，是浏览器缓存所致：DevTools 勾选 Disable cache 或强刷（Ctrl+F5）。

## 四、如何扩展内容（不改页面代码）

所有内容集中在 `assets/js/data.js` 的 `window.APP_DATA`。

### 1. 新增一个景点

在 `pois` 数组追加一项：

```js
{
  id: 'xxx',                 // 唯一 id，路由与打卡都用它
  name: '某某故居',
  short: '某某故居',          // 地图气泡/列表里的短名
  cat: 'former',             // former 故居旧址 | hall 纪念场馆 | relic 革命遗址 | nature 自然人文
  x: 400, y: 700,            // 示意图坐标，画布 viewBox 为 750×1080（左上角为原点）
  mapLabel: '某某故居',
  geo: { lat: 27.9116, lng: 112.4895, r: 120 },  // 真实经纬度（WGS84）与打卡半径（米）
  level: '全国重点文物保护单位',   // 详情页小标题
  hours: '08:00–17:00（周一闭馆）',
  duration: '40 分钟',
  walk: '距故居 300 米',
  archive: '居',              // 没有实景照片时，占位卡上显示的大字
  hero: 'assets/img/poi-xxx.jpg',  // 有实景图就填；没有就删掉这一行
  photos: [],                // 详情页影像墙，可放多张
  tags: ['故居', '全国重点文物保护单位'],
  summary: '一段 60–120 字的概况。',
  highlights: ['看点一', '看点二', '看点三'],
  history: [{ year: '1893', text: '……' }],
  audio: '语音讲解逐句文本，句号分隔，讲解器会按句高亮。',
  storyIds: ['shangwuchang'],
  tips: '参观提示。',
  distance: '景区入口 1.2 公里'
}
```

注意事项：
- **没有实景照片就不要伪造**。删掉 `hero`、保留 `archive` 汉字，页面会自动渲染「实景影像待补」的档案卡样式（当前 `nanan` / `maoshi` / `tezhi` / `dishui` 即为此类）。
- **`geo` 是打卡校验用的真实坐标**，不是示意坐标。打卡时用 `core.js` 的 `distance()` 算球面距离，进入 `r` 米内才允许打卡。当前 `tezhi` / `beilin` / `daotian` 三点是按周边位置估算的，接入前需用现场 GPS 核定（其余六点取自 OpenStreetMap，WGS84）。
- 地图标签位置：若标签压在标记上或超出屏幕，调整 `views-map.js` 里的 `LABELS` 偏移表（`[dx, dy, text-anchor]`）。
- 坐标尽量落在 60–690（x）、90–1000（y）内，避免贴边被裁切。

### 2. 新增一条线路

`routes` 里追加：

```js
{
  id: 'r5', name: '线路名', theme: '主题词', color: '#A32222',
  duration: '半日', distance: '约 2.5 公里', level: '轻松',
  suit: '小学高年级 / 亲子',
  stops: ['guju', 'tongxiang'],        // 引用 pois 的 id，顺序即行程顺序
  intro: '线路简介。',
  goals: ['研学目标一', '研学目标二'],
  schedule: [{ time: '09:00', poiId: 'guju', stay: '40 分钟', note: '现场说明' }],
  tasks: ['任务一', '任务二'],
  cover: 'assets/img/poi-guju.jpg'
}
```

`stops` 决定地图上的路线折线与「下一站」导览顺序；`schedule` 决定详情页行程表。

### 3. 新增一篇故事

`stories` 追加，字段：`id / title / cat（成长·文物·革命·诗词·岁月）/ mins / cover 或 archive / poiIds / excerpt / body（3 段数组）/ quote / knowledge（数组）/ source`。`poiIds` 会自动生成详情页的「故事发生地」入口。

### 4. 新增题目与徽章

- 题目：`quiz` 追加 `{ q, options:[4 项], answer: 正确项索引(0–3), explain }`。
- 徽章：`badges` 追加 `{ id, name, char, desc, rule }`，`rule` 支持 `visit>=1`、`quiz`、`poem`、`route`、`all`（9 个点位全打卡）、`cert`；判断逻辑在 `core.js` 的 `checkBadges()`。

## 五、状态与数据存储

- 存储位置：浏览器 `localStorage`，键名 `shaoshan_red_h5_v1`；隐私模式或禁用存储时自动降级为内存态（刷新即重置）。
- 记录内容：昵称、学员编号、积分、打卡点位与时间、问答最好成绩、诗词完成、观察记录、线路进度与完成记录、收藏、徽章、机构需求提交记录、证书编号。
- 清空：`#/me` 页「清除本机数据」，或在控制台执行 `APP.reset()`。
- 演示前如需干净数据：DevTools → Application → Local Storage 删除该键，或控制台 `localStorage.removeItem('shaoshan_red_h5_v1')`。

积分规则：实地打卡 +10、线路完成 +30、问答每题 +2、诗词全对 +15、观察记录 +5。

### 实地打卡（GPS 校验）

打卡不是点一下就给分：点击「到现场打卡」后调用浏览器定位，用 haversine 算出与点位 `geo` 坐标的距离，进入 `r` 米内才记录打卡。

- 定位失败按原因分四种提示：距离过远（显示实际距离、需进入的半径、当前精度）、未授权定位、点位未配置坐标、超时或不支持定位。
- 只在点击的瞬间读取一次坐标，成功后仅保存 `{ lat, lng, acc, at }`（`state.lastFix`），不记录轨迹。
- `http://` 局域网访问、`file://` 直开都可定位；iOS Safari 与微信内置浏览器要求 `https` 或已验证域名，正式上线需 HTTPS。
- **答辩演示开关**：`#/me` → 设置 → 「演示模式」。开启后跳过距离校验（页面会标注「演示模式」），用于在教室里演示完整打卡流程；演示结束记得关掉。

## 六、内容与合规说明（重要）

1. **试点内容，需场馆核定**：`data.js` 中的史实、年代、开放时间、步行距离均为依据公开史料整理的**试点数据**，上线前须由韶山管理局 / 纪念馆等场馆方逐条核定；页面已注明「地图为示意性导览图，非测绘成果」。
2. **地图为示意图**：SVG 手绘示意，非真实地理坐标，不可用于导航或测绘；实地打卡校验的是 `geo` 里的真实经纬度，两者独立。
3. **图片来源**：`assets/img` 下的实景照片来自项目自有素材，仅用于内部演示；对外发布前需取得拍摄者 / 场馆授权，或替换为授权图库素材。占位卡不伪造实景。
4. **语音讲解**：使用浏览器 `speechSynthesis` 实时合成，不存储音频文件，音色随系统而异；不支持合成的环境会提示改用文字阅读。
5. **未成年人信息**：当前原型不采集手机号、身份证、人脸等敏感信息；机构需求表单仅收集联系人姓名与电话，用于试点联系。面向学生正式上线时须按《个人信息保护法》做最小化采集与监护人告知。
6. **证书为纪念凭证**：`#/cert` 生成的是试点版电子纪念证书，不具官方效力；正式版可对接机构盖章与批量签发。

## 七、已知限制

- 地图为示意图，无真实路径规划；「我的位置」为固定演示点，不跟随实际定位。
- 打卡距离校验依赖浏览器定位精度（户外约 10–30 米），半径设得过小时可能因漂移失败；`tezhi` / `beilin` / `daotian` 三点坐标为估算值，需现场核定。
- 定位在部分浏览器 / 微信内需要 HTTPS，纯 HTTP 局域网访问可能被静默拒绝。
- 语音讲解依赖系统 TTS，iOS 需先有一次用户点击才允许播放（页面已按此设计）。
- 数据仅存本机，换设备 / 清缓存即丢失；无账号体系与后台。
- 图片为压缩后的 sRGB JPEG，未做 WebP / 响应式多尺寸。
- 未做深色模式与横屏适配（锁竖屏体验）。
